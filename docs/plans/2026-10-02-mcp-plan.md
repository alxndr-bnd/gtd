# План: MCP-доступ к gtd для AI-ассистентов

2026-10-02 · Alexander Bondarchuk · задача [SERBITO-375](https://serbito.atlassian.net/browse/SERBITO-375) · в gtd: #22

> Копия плана в репозитории — чтобы по истории коммитов было видно, что разрабатывалось и по каким задачам.

## Цель

Дать Claude и другим ассистентам читать и писать задачи gtd через MCP: «запиши в инбокс», «что у меня @crossfit-ns», «закрой 42», недельный обзор — без браузера и копипасты.

**Не цели:** сторонние трекеры (Todoist и т. п.), отдельный сервис или БД, новые методы входа.

## Исходное состояние (разведка v0.24.0)

- Логика задач уже есть: `capture()` (парсер дат, `#проект`, `@контекст`), `/api/items`, `/move`, `/projects`.
- Инфраструктура: Cloud Run `gtd` (europe-west1, `min-instances=0`, `max=2`), Cloud SQL, деплой по тегу с Trivy.
- Вход: Google (ID-токен через GIS), email-код, Telegram → cookie `sid`. Bearer-токенов нет.
- `Guard` требует same-origin и `application/json` для `/api/*` — внешний MCP-клиент будет отрезан.
- claude.ai custom connectors поддерживают DCR, CIMD, client ID/secret и static headers (бета); callback `https://claude.ai/api/mcp/auth_callback`.

## Решение

MCP-сервер внутри существующего FastAPI: `FastMCP(..., stateless_http=True)` смонтирован на `/mcp`. Stateless обязателен из-за scale-to-zero и двух инстансов.

Сам gtd становится OAuth authorization server; Google — лишь один из способов войти на экране `/authorize`, поэтому все три метода входа работают и для MCP.

## Инструменты MCP

- `capture(text)` — тот же парсер, что в вебе и боте, источник `mcp`
- `list_items(list, context?, project?)` — inbox / next / waiting / calendar / someday / reference / done
- `move_item(id, list)`, `complete(id)`, `update_item(id, …)`
- `list_projects()` — с пометкой «без следующего действия»
- `weekly_review()` — сводка для еженедельного обзора

Все вызовы работают от `uid` из токена; данные других пользователей недоступны.

## Безопасность

- Токены хранятся как SHA-256, как сессии; срок жизни и отзыв.
- Scope на старте один (`tasks`), доступ только к своим данным.
- Rate limit на `/mcp` и `/token`.
- Аналитика по-прежнему без содержимого задач.

## Риски

- Static headers в claude.ai — бета; для claude.ai надёжнее этап 3.
- `app.py` на 2573 строки: без этапа 0 MCP усложнит монолит.
